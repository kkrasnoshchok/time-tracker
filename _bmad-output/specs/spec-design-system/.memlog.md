- (capability) CAP-1 Semantic tokens (colors, type, spacing, radii, ring) and base components (button primary/ghost, card, input, badge, category dot, category token) in App/; no literals outside the token layer.
- (capability) CAP-2 Category color rendering: any stored colorHex shown as one of 8 tones.
- (capability) CAP-3 Categories tab: ColorPicker and randomColor() removed; choice of 8 tones; new category gets first unused tone, cycling when all 8 used.
- (capability) CAP-4 Palette restyled to DESIGN.md (first in rollout).
- (capability) CAP-5 Journal restyled (list, day header, rows, running row).
- (capability) CAP-6 Menu bar item and popover restyled.
- (capability) CAP-7 Remaining surfaces: entry detail, add-entry sheet, Categories chrome, Settings, error strip (no red).
- (capability) CAP-8 'долго' marker on any entry (running or finished) with duration >= 8h, text 'долго', gray caption next to duration in Journal row and popover.
- (decision) Migration of old colors = render-time mapping, no data write. Reason: Core PaletteViewModel.categoryColors still hands out bright system hexes on in-palette category creation and Core is off-limits, so a one-time rewrite would be undone.
- (decision) Mapping: the 8 Core default hexes map 1:1 and distinct (blue->slate, green->moss, orange->clay, red->rose, purple->plum, cyan->lagoon, yellow->ochre, brown->taupe); any other hex -> nearest tone by Oklab distance, ties by token order.
- (decision) Categories tab keeps a choice among the 8 tones (user choice); ColorPicker free input removed, randomColor() removed. Stored value is the tone's hex.
- (decision) 'долго' threshold 8 hours, wording 'долго', applies to any entry >= threshold incl. finished ones (so it is visible before the hand fix); disappears when duration drops below.
- (constraint) Token and component layer is semantic (surface-*, text-*, action-*), light theme only; Liquid Glass/materials, gradients, shadows, red/green/blue banned in our surfaces per DESIGN.md.
- (constraint) 'now' for the 'долго' check comes from TimeProvider, never Date().
- (assumption) Threshold predicate and hex->tone mapping are small pure functions placed in App/ (Core off-limits), unit-tested with injected time; deviates from CLAUDE.md 'all logic in Core' by user instruction.
- (question) Should the 'долго' predicate and mapping be allowed into Core later after the design stage (CLAUDE.md rule vs this spec)?
- (question) Carried from EXPERIENCE.md Open items, out of scope here: stop-timer hotkey, 'stop now' quick action in Entry detail.
